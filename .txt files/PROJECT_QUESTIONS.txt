Q6: How does the AI recommendation system work?
LOCATION: django project backend/recommendations/recommendation_engine.py (entire file)
MAIN CLASS: RecommendationEngine (line 60)
TECHNOLOGY: TensorFlow Hub Universal Sentence Encoder v4
DETAILS:
    Step 1: Movie Indexing
        - Method: index_movie() (line 120)
        - Converts movie to text: "Primary Genre: Action. Type: Movie. Year: 2020. Plot: ..."
        - TensorFlow creates 512-dimensional embedding vector
        - Stores in vector_db/ folder (numpy arrays)
    
    Step 2: User Profile Creation
        - Method: build_user_profile() (line 300)
        - Analyzes user watch history + favorites + manual genre selection
        - Creates weighted genre preference dictionary:
            Example: {"Action": 450, "Drama": 200, "Comedy": 100}
        - Weights:
            * Completed movie watch: 300 points
            * Continue watching (>20%): 100 points
            * Favorite: 80 points
            * Manual genre selection: 150 points
            * Recent completed (last 7 days): 3x multiplier
    
    Step 3: Multi-Genre Recommendations (FIXED VERSION)
        - Method: get_recommendations() (line 400)
        - OLD BUG: After watching different genre, recommendations flipped 100% to new genre
        - FIX: Smart genre detection + forced interleaving
        - Identifies top 2-3 important genres (>= 15% of total weight)
        - Queries vector DB separately PER GENRE
        - Interleaves results proportionally:
            * Primary genre: 60% of results (12 out of 20)
            * Secondary genre: 30% of results (6 out of 20)
            * Others: 10% of results (2 out of 20)
        - Result: User sees MIX of all their preferences, not just dominant one

Q8: How does the AI learn from user behavior?
LOCATION: django project backend/accounts/recommendation_feedback_views.py (entire file)

SELF-LEARNING SYSTEM:
    Every time user clicks a recommendation:
        - Frontend tracks: position in list (1, 2, 3... 100)
        - Backend calculates feedback score:
            * Position 1-5: +10 points (strong positive signal)
            * Position 6-10: +5 points

        - Future recommendations boost high-scoring movies
EXAMPLE:
    User clicks "Inception" at position 3 → +10 points
    AI prioritizes "Inception" in future recommendations

Q10: How does genre detection work?
LOCATION: django project backend/recommendations/recommendation_engine.py → get_top_user_genres() (line 550)
DETAILS:
    Analyzes user activity to find IMPORTANT genres:
        - Calculates genre weights (completed: 300, favorites: 80, etc.)
        - Total weight example: 800 points across all genres
        - Genre needs >= 15% of total (120 points) to be "important"
        - Returns top 2-3 genres that pass threshold
    Example calculation:
        Action: 450 points (56% of 800) → IMPORTANT
        Drama: 200 points (25% of 800) → IMPORTANT
        Comedy: 100 points (12.5% of 800) → NOT important (< 15%)
        Horror: 50 points (6% of 800) → NOT important
    Result: User's important genres = ["Action", "Drama"]

                {'title': {'$regex': search, '$options': 'i'}},
                {'director': {'$regex': search, '$options': 'i'}},
                {'cast': {'$regex': search, '$options': 'i'}},
                {'description': {'$regex': search, '$options': 'i'}}
            ]
        
        # Add type filter
        if type:
            query['type'] = type  # "Movie" or "TV Show"
        
        # Add genre filter
        if genre:
            query['listed_in'] = {'$regex': genre, '$options': 'i'}
        
        # Apply query
        movies = Movie.objects(__raw__=query)
        
        # Sort
        if sort == 'year-desc':
            movies = movies.order_by('-release_year')
        elif sort == 'title-asc':
            movies = movies.order_by('title')
    
    MULTIPLE FILTERS COMBINE:
        Example: search="batman" + genre="Action" + type="Movie"
        Result: Action movies with "batman" in title/cast/director

Q36: How does the multi-genre AI fix work?
LOCATION: django project backend/recommendations/recommendation_engine.py (lines 400-600)
THE BUG:
    User watches: 10 Action movies → recommendations = 100% Action ✅
    User then watches: 2 Drama movies → recommendations = 100% Drama ❌
    
    Problem: Recent genre completely overrides previous preferences

THE FIX:
    1. Smart genre weight calculation (line 300)
        - Completed movies: 300 points
        - Recent completed (last 7 days): 3x multiplier (900 points)
        - Continue watching: 100 points
        - Favorites: 80 points
        - Manual selection: 150 points
        
        Example weights:
            Action: 10 completed × 300 = 3000 points
            Drama: 2 recent completed × 900 = 1800 points
            Comedy: 5 favorites × 80 = 400 points
    
    2. Identify important genres (line 550)
        - Total weight: 3000 + 1800 + 400 = 5200
        - Important threshold: >= 15% of total (780 points)
        - Important genres: Action (57%), Drama (34%)
        - Comedy excluded (< 15%)
    
    3. Forced per-genre querying + interleaving (line 450)
        - Query vector DB separately for Action
        - Query vector DB separately for Drama
        - Interleave proportionally:
            * Action: 57% of 20 = 11 movies
            * Drama: 34% of 20 = 7 movies
            * Others: 9% of 20 = 2 movies
        - Result: [A,A,D,A,D,A,A,D,A,D,A,A,D,O,A,D,A,A,O,D]
    
    4. Prevents clustering
        - OLD: All Action movies first, then Drama
        - NEW: Interleaved mix, guaranteed variety

Q39: How does TensorFlow Hub embedding work?
LOCATION: recommendations/recommendation_engine.py → generate_embedding() (line 100)
TENSORFLOW HUB:
    MODEL: Universal Sentence Encoder v4
    URL: https://tfhub.dev/google/universal-sentence-encoder/4
    
    INPUT:
        Movie text: "Primary Genre: Action. Type: Movie. Year: 2020. Plot: A team of mercenaries..."
    
    OUTPUT:
        512-dimensional vector: [0.023, -0.145, 0.678, ..., 0.234]
    
    HOW IT WORKS:
        1. Load pre-trained model (trained on billions of sentences)
        2. Convert movie to text description
        3. Model creates embedding (vector representation)
        4. Similar movies have similar vectors (measured by cosine similarity)
    
    EXAMPLE:
        "Action thriller with explosions" → [0.1, 0.8, 0.2, ...]
        "Action movie with car chases" → [0.12, 0.78, 0.25, ...] (very similar!)
        "Romantic comedy with jokes" → [-0.3, 0.1, -0.5, ...] (very different!)
    
    SIMILARITY CALCULATION:
        cosine_similarity(vector1, vector2) = dot_product / (norm1 * norm2)
        Result: 0.0 (completely different) to 1.0 (identical)
